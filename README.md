## Prodigy InfoTech Data Science Internship - Task 01

## Population Distribution Visualization

### Objective

Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable.

### Dataset

The dataset used for this task is the World Bank population dataset provided by Prodigy InfoTech.

### Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook
* VS Code

### Work Performed

* Loaded the population dataset using Pandas.
* Examined the structure of the dataset.
* Selected population values for 2024.
* Handled missing values.
* Created a histogram to visualize the population distribution.
* Used a logarithmic scale to make the distribution easier to interpret.

### Key Observation

The population distribution is strongly right-skewed. Most countries and regions have relatively smaller populations, while a small number of countries have very large populations.

### Output

The final histogram provides a visual representation of how population values are distributed across countries and regions.
